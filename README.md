## 更新与使用

已有用户：Chrome 扩展管理页重新加载原扩展，再刷新标注工作台。原扩展 ID 和加载目录保持不变。

新用户：解压安装包，Chrome 开启开发者模式，加载包含 manifest.json 的目录。详细步骤见《安装与使用.txt》。

1. 在设置中填写 V-API 或硅基流动 API Key。密钥只保存在当前浏览器会话，留空保留已有密钥。
2. 首页选择「IP 识别」或「文字检查」。
3. 默认按时间轴每 10% 抽一帧，共 11 帧；可选 5%、20%、25%，分别为 21、6、5 帧。包含首尾附近画面，不是抽取原视频总帧数的百分比。
4. 点击「识别全部题」或「检查全部题」，结果自动显示在每题评分下方。
5. 失败可重试，停止后可继续。运行期间先停止再切换模式。模式切换会清理当前页面另一模式的结果并恢复所选模式缓存。

## IP 识别

识别具体动漫、游戏、影视虚构角色、品牌、明确平台归属和知名地标。普通物品和泛化卡通形象不输出，真人身份留给人工确认，不进行真人姓名或名人身份识别。

结果示例：江户川柯南（名侦探柯南） · 置信度 92%。

重点比较作品归属、角色服饰、发型、配色、道具等独特特征。置信度为模型估计，经保守证据约束：单帧最高 85、只有一项独特特征最高 80、总上限 97；低于 65 不强行输出。这些阈值未经真实样本校准，不是统计正确率。

可选「联网增强」默认关闭。开启后，视觉和 V-API 搜索通道同时接收同一组抽样帧、独立判断。相同名称与相容作品归属取两路较低置信度；同类 IP 在同一帧存在冲突时减 20。搜索独有候选不会直接注入，搜索失败保留视觉结果。搜索来源仅在侧栏详情展示；是否返回搜索依据与是否返回增强响应分别记录。

## 文字检查

仅使用视觉模型，IP 模式的联网设置保留，但在文字模式隐藏且不触发搜索。为保留小字细节，抽样图片最长边为 1536 像素；IP 模式为 1024 像素，不放大低分辨率原片。

三个维度独立判断：

- 完整度：笔画、字符或文本区域有无缺失、裁切、遮挡。结合相邻抽样帧判断，不把正常滚动、换行或逐字字幕直接判为残缺。
- 乱码：有无伪字、异常笔画、杂乱字符或字符融合。不把模糊、小字、不熟悉的语言和艺术字体直接判为乱码。
- 正确性：可读的错别字、拼写和上下文明确的用词错误。没有参考原文、专名不确定或内容不可读时标记待确认，不声称完成原文一致性比对或事实核查。

结果会给出三个结论及模型估计置信度；存在错误时附简短问题和可确认的建议。展开详情可看画面原文字片段、检查依据及全部问题，并定位对应视频进度。低置信度结论降为待确认；无文字明确显示「抽样帧未发现文字」，不算通过。不会自动修改视频字幕或平台答案。

抽样检查不能证明全片文字正确，短暂出现的问题可能遗漏；需要时提高抽帧密度并人工复核。

## 模型与数据

- 默认视觉：V-API gemini-3.8-flash，Gemini 原生多图输入。
- 备选视觉：硅基流动 Qwen/Qwen3.5-397B-A17B，Chat Completions 多图输入。
- IP 联网增强：V-API gemini-3.8-flash-search。使用硅基流动视觉时，也需要 V-API Key 才能增强。
- 模型请求只发送到 api.gpt.ge 或 api.siliconflow.cn；视频读取来自标注平台同源地址。
- 默认单片 80 MB、最长 600 秒。本地解码后只上传抽样 JPEG，不上传原始视频、音轨、生成提示词或人工分数。
- 兼容 media_path、sd2_5_video_path、video_path、video_url 等字段。按完整题包身份和精确 data-id 注入，任务切换会中止旧请求、清理旧显示。
- IndexedDB 保存结论、画面依据、模型及媒体摘要，文字模式还保存可见文字片段；不保存原视频或帧图片。缓存按模式、题目、视频路径、提示词版本、模型、采样配置隔离。
- 设置中可读取账户模型列表并测试视觉接口；实际可用模型、权限和费用以服务响应为准。

## 开发与发布

需要 Node.js 22 或更新版本。

```sh
npm ci
npm test
npm run package
```

可选浏览器检查：安装 Chrome 后运行 `npm run test:browser`。Chrome 不在默认路径时设置环境变量 `CHROME_PATH`。

浏览器测试使用独立临时 Chrome、合成视频和受控模型响应。覆盖两页整包、抽帧、失败重试、搜索回退、模式切换、模式缓存隔离、刷新及翻页恢复、文字检查注入和零评分提交。这些检查不证明真实模型的 IP 或文字识别准确率。

node build.mjs 生成 out/卓觅识界-PE视觉助手-v0.4.1.zip，并生成可直接加载的 out/extension 目录。安装包包含 LICENSE.txt、NOTICE.txt、安装说明和 zmidata 图标。
