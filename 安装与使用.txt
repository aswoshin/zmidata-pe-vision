已有用户（当前电脑）
1. 打开 Chrome 扩展程序管理页。
2. 在原帧评/识万物/卓觅识界扩展卡片点击“重新加载”。
3. 刷新标注工作台，右下角打开“卓觅识界”。
原扩展 ID 与已加载目录保持不变，不必删除或重新安装。

新电脑安装
1. 将 ZIP 完整解压到固定文件夹。
2. Chrome 扩展程序管理页开启开发者模式。
3. 点击“加载已解压的扩展程序”，选择包含 manifest.json 的文件夹。
4. 打开标注工作台，在“卓觅识界 → 设置”填写自己的 V-API 或硅基流动 API Key。

双模式使用
- 首页点击“IP 识别”或“文字检查”，运行中先停止再切换。
- IP 识别：只报告具体 IP、角色、品牌及明确归属和模型估计置信度。真人身份由人工确认。
- 文字检查：分别判断完整度、乱码和正确性；无文字、不可读、缺少参考的情况单独提示。可展开查看文字片段、检查依据和问题，并定位到对应画面。
- 默认按视频进度每 10% 抽帧，共 11 帧；短暂字幕可改为每 5% 抽帧。
- 点击“识别全部题”或“检查全部题”，结果显示在评分下方；切换模式会恢复各自结果。
- IP 模式可选视觉与联网并行增强；文字模式仅使用视觉模型，不进行联网搜索。
- 置信度为模型估计，未经真实样本准确率校准。抽样结果不代表全片所有画面。
- 不自动打分，不修改、保存或提交平台评分。
